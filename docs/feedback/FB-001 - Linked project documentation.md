# FB-001 - Linked project documentation

## Source and request
In this project's conversation, the user supplied an Instagram reel transcript
and asked for all project documentation in an Obsidian vault. Obsidian Desktop is
already installed. They want decisions, issues, feedback and reusable learnings
connected so future development has accessible context.

## Interpretation
Maintain project knowledge with explicit relationships and evidence, while
preserving the root SRS and ordered task checklist. The reel's claimed acceleration
on another app is anecdotal and is not a measured result for FilingGuard.

## Response
[[docs/decisions/ADR-002 - Repository as documentation vault]] selects the setup.
[[Home]] is the entry point; [[docs/knowledge/Documentation Workflow]] describes
maintenance. Desktop opening/registration remains a user-visible setup step.
