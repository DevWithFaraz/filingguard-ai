# Asymmetric curved papers

## Source and need
User said D003 flattened the papers and lost cursor/hover response. Requested
gentle S-curves, different left/right silhouettes, clearer heading letter counters
and a larger footer logo relative to its tagline, with aligned links.

## Response and validation
D004 implements opposing S-bends with different proportions and rotations,
cursor tilt and proximity lift, genuine SemiBold heading and footer rebalance.
Ten desktop/mobile browser tests passed; screenshots inspected. User aesthetic
acceptance is pending. No audience-research claims are implied.
