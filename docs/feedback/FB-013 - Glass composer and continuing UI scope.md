# Glass composer and continuing UI scope

## Source
User request in this chat, October 11, with a screenshot of the homepage input box.
Paraphrase: remember the existing UI scope during remaining development and show
how the rounded input form looks with a beautiful glassmorphism treatment.

## Need and response
Keep the homepage's identity, coherent step navigation, timely/quick actions and
purposeful accessible motion as continuing project guidance. Record it in
[[AGENTS]] and [[docs/product/UI direction]]. The specifically requested homepage
exception changes only the composer material and its text contrast: visible frost,
lilac translucency, a light-catching edge and layered shadow over the existing
background. Preserve the form's layout, controls, state and request behavior.
Use one blurred surface; nested fields retain legible solid control treatments.
Opaque fallbacks support reduced transparency, increased contrast and forced colors.
