# Image-backed filing composer

## Source and need
User wants a centered translucent text/file input, FilingGuard-AI heading in
Avalance, a user-designed HD background and possibly a logo. They supplied
AirForShare, Kombai, palette and font/motion references and requested responsive
phone/tablet layouts, scroll animation and a future explanatory video.

## Response and confirmed decisions
User approved Text / PDF / Demo, court selection, AI-used input and Run review,
without generic chat/image uploads. User will design the image and look for a
free font source. They supplied eight GC Avalance Demo TTF weights and reported
direct creator permission via DM for using them on this site. Proceed on that
user-reported permission; it is not independently verified license evidence.
No font has been embedded yet. User will provide the background later and asked
that implementation not wait for it.
User says not to worry about the deadline: the internal feature-freeze constraint
is no longer governing this work, but no official event deadline change is inferred.

Plan: [[docs/product/UI direction]]. Implementation continues on Phase 2/3
foundations, with bounded subagents. No final visual UI has been built.
Validate with actual assets, keyboard/reduced-motion tests and multi-viewport
screenshots before calling the visual direction implemented or verified.
