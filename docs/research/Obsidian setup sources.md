# Obsidian setup sources

Checked official documentation on September 26, 2026:

- [Create a vault](https://obsidian.md/help/vault): an existing folder can be opened
  as a vault. This supports using the repository directly.
- [Templates](https://obsidian.md/help/plugins/templates): the core plugin uses a
  selected template folder and supports title/date/time substitution.
- [Obsidian URI](https://obsidian.md/help/uri): note-opening URIs resolve against
  known vaults. Preparing a folder does not establish desktop registration.

These sources support the documented setup, not the reel's productivity claims.
Local configuration and note links can be checked on disk; desktop rendering and
registration require opening the folder in the app.
